# 馬股每日追蹤 (stockchecker)

追蹤馬來西亞銀行股、REIT 與大盤的每日儀表板。純 Python 標準函式庫 + 一頁 HTML，**不需要 pip install，也不需要 API 金鑰**。

## 快速開始

```bash
python3 fetch.py     # 抓最新資料
./serve.sh           # 開伺服器，然後瀏覽器打開 http://localhost:8777
```

`index.html` 也可以直接雙擊開啟（資料同時寫成 `data/data.js`，所以 file:// 也讀得到）。

## 今日重點（自動分析）

每次更新後 `analyze.py` 會挑出值得看的事，顯示在頁面最上方，點一下跳到該檔。

**這是規則判斷不是 AI** —— 更新跑在 GitHub 的機器上，沒有模型可以呼叫。
好處是結果穩定、可預期、不會編造；限制是只認得下面這些情況：

| 類別 | 觸發條件 |
|---|---|
| 價格 | 創 52 週新高/新低、單日 ±2% 以上、跑輸/跑贏大盤 2 個百分點以上 |
| 量能 | 成交量達均量 2 倍以上（配合下跌時列為最高等級）|
| 行事曆 | 7 天內財報、7 天內除息、5 天內剛除息 |
| 公告 | 3 天內的新公告；大股東持股變動**聚合後**達 500 萬股才列（EPF、KWAP 天天微調，逐筆列會洗版）|
| 估值 | P/B < 1 且 ROE ≥ 10%、派息率 > 100%、殖利率 ≥ 7% |
| 油棕 | CPO 一個月變動 ≥ 3% |

每檔最多兩條、總共最多十條，避免單一檔把整個重點區佔滿。
派息率的說明會依產業調整（REIT 的派息率天生就高，一般公司超過 100% 才是警訊）。

只陳述事實與數字的意義，不做買賣建議。

## 重點報導（每檔一份）

展開任一檔，圖表下方有一份自動整理的摘要，五個面向：

| 欄位 | 內容 |
|---|---|
| 價格 | 收盤、單日、一個月、三個月、距 52 週高點。**一個月內若有除息，會標明除息佔了幾個百分點**——不然會把除息誤判成下跌 |
| 公告 | Bursa 官方公告的中文內文（抓得到的話），最近兩則 |
| 報導 | 則數、主題分類、來源媒體。**媒體內文抓不到，所以只歸納主題不引述內容** |
| 數字 | P/B、P/E、ROE、殖利率、派息率、每股淨值、分析師目標價 |
| 留意 | 創新低、派息率過高、ROE 偏低、估值與獲利不同步、下次財報日 |

由 `digest.py` 產生，跟「今日重點」一樣是規則判斷不是 AI。
**刻意不寫「看好/看壞」**——素材不足以支撐那種結論，而且那是投資建議。

## 最愛

每一列最左邊有顆星，點一下加入最愛。最愛會**釘在列表最上面自成一區**，
同時從原本的分類移除（避免同一檔出現兩次），排序照你加入的先後。

存在瀏覽器的 localStorage，所以是**每台裝置各自一份**——手機和電腦的最愛不會同步。
排序欄位不會打亂最愛區的順序。

## 手機

窄螢幕會自動換版型：表格變成兩行式列表，點個股不是往下撐開，而是從底部滑上來的全螢幕面板
（在手機上內嵌展開會把下面的股票推很遠，看完找不回原位）。

iPhone 可以「分享 → 加入主畫面」，有 `manifest.webmanifest` 所以會用獨立視窗開啟，沒有網址列。

## 在手機上看（人不在電腦旁）

網頁掛在 GitHub Pages，**每天由 GitHub 在雲端自動更新，不需要你的 Mac 開機**：

> https://evolee1100.github.io/stockchecker/

排程寫在 `.github/workflows/daily.yml`，每週一到週五跑**三次**（馬來西亞時間）：

| 時間 | 用意 |
|---|---|
| 09:30 | 開盤後，看隔夜消息與開盤反應 |
| 13:00 | 午盤休息 |
| 18:30 | 收盤後，當日結算 |

每次都是：抓價量 → 抓基本面 → 抓新聞與公告 → 翻譯 → 自動分析 → 存快照 → 重新部署。

想立刻更新一次不用等排程：

```bash
gh workflow run daily.yml --repo evolee1100/stockchecker
```

或在 GitHub 網頁的 Actions 分頁按 **Run workflow**。

## 設定每天自動更新（本機，選用）

上面的雲端排程已經夠用了。如果你還想讓 Mac 自己也留一份本機資料：

```bash
./install_daily.sh          # 每天 18:30（馬股 5pm 收盤後）
./install_daily.sh 20 00    # 或改成每天 20:00
```

（Mac 關機或睡眠時這個不會跑，所以出門在外請看上面的 GitHub Pages 網址。）

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `watchlist.json` | **要增減股票就改這個**。每檔需要 `symbol`（Yahoo 代碼，Bursa 為 `代碼.KL`）與 `sa`（stockanalysis 代號）。美股的 `sa` 要加 `us:` 前綴（例：`us:NVDA`）——馬股在 `/quote/klse/`、美股在 `/stocks/`，路徑不同 |

| `index.html` | 儀表板本體（單一檔案，無外部相依）|
| `data/history/` | 每天一份快照，之後可以回頭比對 |

## 圖表資料的精度取捨

近一年存**日線**，五年存**週線**。純日線存五年 × 46 檔會讓 `data.js` 膨脹到 4-5MB，
手機載入太慢；混合之後是 1.7MB。切到 3年/5年 時自動換成週線，讀數會標示「（週線）」。

資料不足的標的會自動隱藏長區間按鈕，而不是給一張空圖
（例如棕櫚油走 MPOB 官方牌價，只拿得到半年）。

## 快取

`data/data.js` 用固定網址載入時會被瀏覽器快取住，**從手機主畫面開啟的 App 尤其頑固**，
會出現「明明部署成功但畫面沒更新」的狀況。兩個處理：

1. 部署時把建置時間戳進網址（`data/data.js?v=20260906203000`），網址一變就一定重新抓
2. 頁首有一顆 `↻` 按鈕，帶時間戳強制重載——主畫面 App 沒有網址列，沒有這顆就沒辦法手動更新

## 資料來源

- **價量、52週高低、除息紀錄** — Yahoo Finance chart API
- **基本面** — stockanalysis.com
- **媒體報導** — Google News RSS（The Edge、The Star、NST、Bernama、EdgeProp⋯）
- **官方公告** — klsescreener 轉載的 Bursa 公告（財報、派息、股權變動）

## 翻譯

英文資訊會轉成繁體中文，分三層處理：

1. **規則表** — Bursa 公告標題是套版的，用正規表示式對照翻譯，比機器翻譯準且不會失敗
2. **機器翻譯** — 新聞標題是自由文字，Google 為主、MyMemory 備援
3. **保留原文** — 兩者都失敗就顯示英文，不會出現半截或亂碼

公司名與金融縮寫（OPR、NIM、DPU、EPF⋯）在送去翻譯前會換成佔位符保護，翻完還原；
**還原失敗就整句退回英文**。翻譯結果快取在 `data/translations.json` 並進版控，
所以每天只需要翻新增的標題。翻譯失敗不寫進快取，下次更新會再試一次。

媒體報導與 Bursa 公告的區塊標題旁各有一組「中文 / 原文」兩顆按鈕，
目前在哪個模式一眼看得出來。每則新聞另外有自己的原文彈窗。

### 公告內文

Bursa 公告會抓內文回來翻譯，分兩種：

- **持股變動類**（Changes in Sub. S-hldr's Int）是表格式的，硬翻只會得到一堆零碎欄位名。
  改成規則解析成一句中文摘要：「某某 於 2026-09-02 減持 7,418,400 股（直接持股）。變動後持有 …」
- **新聞稿類**抓英文全文（上限 900 字）後分段翻譯。切塊上限 450 字元是被 MyMemory
  逼出來的——它免費版單次查詢上限 500 bytes。

**媒體報導抓不到內文。** Google News 把真實網址藏在 JS 後面（base64 解不出、重導向轉回自己、
batchexecute 也拿不到），The Star / NST / The Edge 的 RSS 全部 404，klsescreener 的新聞頁是
JS 載入的。所以報導只有標題的中英對照，要讀全文得開來源網頁。

Yahoo 的 `quoteSummary` / `v7/quote` 端點現在需要認證，抓不到基本面，所以基本面走第二個來源。若該來源失效，價量仍會正常更新，只是基本面欄位會空著。

## 儀表板會自動標出的訊號

- 創 52 週新低 / 距高點超過 15%
- 單日漲跌超過 ±2%
- 成交量放大 2 倍以上（配合下跌時特別值得注意）
- 近 30 天內除息（解釋「無故下跌」很多時候就是這個）
- P/B < 1、ROE 高低、派息率超過 100%

## 油棕

CPO 價格用 **MPOB 官方每日牌價**（馬來西亞棕油局，RM/噸）：

> https://bepi.mpob.gov.my/admin2/price_local_daily_view_cpo_msia.php?more=Y&jenis=6M

價格藏在頁面的 Highcharts 設定裡（`categories` 是日期、`data` 是價格），`jenis=6M` 給 122 個交易日。

> 早期版本用 CME 的美元合約 `CPO=F` 乘匯率換算，那是估算值。MPOB 才是收購商與小園主
> 實際參照的官方牌價，已經換掉。

### 鮮果串（FFB / TBS）收購價試算

展開「毛棕櫚油 CPO」那一列：

```
鮮果串價 = 毛棕櫚油價 × 出油率(OER)

4,559.67 × 18.75% = RM 854.94 /噸
```

- CPO 價預設帶入 **30 日均價**（官方牌價每日加總 ÷ 30），一鍵可切換成當日價
- 出油率由收購商提供，自己填，會存在瀏覽器裡
- 出油率 18.75% 時算出 RM 855/噸，落在小園主鮮果串行情 RM850–980 的區間內

## 展開單一個股

點表格任一列會展開：走勢圖（可切 1個月 / 3個月 / 半年 / 1年 / 3年 / 5年，滑鼠移過去會顯示該日價格）、完整數據、**媒體報導**與 **Bursa 官方公告**兩欄並排。公告是第一手的「到底發生什麼事」，報導則有解讀與脈絡。

## 注意

資料為收盤價，不是即時報價。本工具只做資訊整理，不構成投資建議；下單前請以 Bursa 公告與券商資料為準。
